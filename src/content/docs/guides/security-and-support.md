## 网络架构与数据隐私

- **接入链路**：主接口 `https://api.bozzii.com` 通过**阿里云 CDN 就近边缘节点**加速接入，自动优化跨地域握手与流式传输稳定性。
- **无状态中转**：网关仅作无状态请求转发，**不落盘、不留存任何对话提示词（Prompt）与模型回复（Completion）内容**。
- **仅记录元数据**：控制台使用日志仅保留计费与排障所需的最小元数据（请求时间、`Request ID`、模型名、Token 计数、耗时与扣费金额）。
- **零训练承诺**：平台郑重承诺**绝不将客户请求内容用于任何模型训练或微调**。请勿传输依法或依合同受限、或您无权传输的数据，具体条款以[隐私政策](https://ai.bozzii.com/privacy-policy)与[服务条款](https://ai.bozzii.com/user-agreement)为准。

## 官方直连与真实性自检

我们欢迎企业研发团队随时对关键模型进行独立核验与指纹对比：

1. **Token 计数与响应头核验**：发送固定测试提示词，核对 `usage.prompt_tokens` / `completion_tokens`、响应结构及 `system_fingerprint` / `id` 前缀是否与官方规范一致。
2. **Prompt Cache 真实命中验证**：发送超过 2,048 Token 的稳定前缀连续请求两次，检查第二轮 `cached_tokens` / `cache_read_input_tokens` 命中率与控制台日志扣费折扣是否相符。
3. **长思考 SSE 保活验证**：在推理模型上开启 `stream: true` 观察每 10 秒一次的 `: PING` 心跳注释，确认长连接稳定不中断。

如需获取自动化自检脚本（`bozzii_verify.py`，支持边缘头、指纹基线对比、缓存命中、SSE 保活与协议核验），请联系专属客户支持或大客户商务。

## API Key 防盗刷与安全最佳实践

为避免令牌泄露造成异常扣费，强烈建议所有企业团队落地以下 5 项防护：

1. **按业务 / 成员拆分独立令牌**：切勿全团队共用同一把 Master Key，一人一 Key 或按应用隔离，泄露时可单点吊销而不影响其他服务。
2. **设置额度上限与过期时间**：在控制台 [API 密钥](https://ai.bozzii.com/keys) 为每个 Key 配置合理的可用额度与有效期，杜绝「无限额 Key 泄露刷爆余额」。
3. **绑定允许调用的模型白名单**：仅勾选当前应用所需的模型，防止泄露后被恶意刷高单价推理模型或生图接口。
4. **配置 IP 白名单（服务端调用）**：生产服务器出口 IP 固定时，强烈建议为生产 Key 配置 IP 白名单。
5. **严禁明文入库或写入前端**：永远通过环境变量或密钥管理服务注入 `sk-` 令牌，严禁提交到 Git 仓库或暴露在浏览器端代码中。

## 客服支持、故障排查与反馈奖励

### 提交排障三要素

在控制台 [使用日志](https://ai.bozzii.com/usage-logs/common) 点击报错记录即可一键复制**已脱敏的排障摘要**；手动反馈时请提供：

1. **`Request ID`**（日志详情或响应头中的唯一请求标识）
2. **报错发生时间与模型 ID**
3. **HTTP 状态码或报错摘要**（无需提供您的 API Key 或敏感业务正文）

- **控制台专属客服页**：[https://ai.bozzii.com/contact](https://ai.bozzii.com/contact)（可查看大客户商务 **Jerry**、用户运营 **Ming**、客户支持 **小白** 联系方式及微信 / 飞书二维码）

- **服务状态页**：[https://status.bozzii.com](https://status.bozzii.com)
